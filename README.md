# مكتبة طموح 2030 — Android

نسخة أولية فعلية لتطبيق Android مبنية بـ Kotlin + Jetpack Compose.

## المزايا الموجودة
- واجهة عربية RTL وهوية ألوان مستوحاة من شعار المكتبة.
- أقسام تعليمية سعودية.
- أزرار واتساب 1 و2 و3 مع الرقم الثالث قابل للإضافة لاحقًا.
- رابط مجموعة واتساب للإعلانات.
- شاشة إعدادات لتعديل الأرقام والرابط دون تعديل الكود.
- تنقل سفلي بين الرئيسية والمكتبة والتحميلات والإعلانات والمزيد.

## تشغيل المشروع
افتح المجلد في Android Studio ثم نفّذ Sync/Build. يحتاج المشروع إلى Android SDK 35 واتصال إنترنت لتنزيل تبعيات Gradle.

## الخطوة التالية المهمة
لإدارة الأرقام والرابط والملفات من أي جهاز، اربط شاشة الإعدادات بقاعدة بيانات سحابية (Firebase Firestore/Storage أو API خاص). كذلك تُضاف شاشة دخول للمشرف ولوحة رفع ملفات PDF/Word.
